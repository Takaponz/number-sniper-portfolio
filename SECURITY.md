# Security Policy

## Supported version

Only the latest commit on `main` is reviewed for security reports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub Private
Vulnerability Reporting and include the affected commit, reproduction steps,
impact, and any suggested mitigation.

This portfolio build uses a non-network advertising stub by default and is not
a production service. The retained AdMob integration example contains Google
test identifiers only.
